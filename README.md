# Career Radar — прототип 0.2

Python 3.10+, без внешних библиотек. Все 24 согласованные компании в companies.json; названия-алиасы предварительные, не подтверждены ID работодателей.

## Локальная проверка
python -m unittest -v
python radar.py --dry-run --fixture demo.json

## Подключение Telegram
Создайте бота через @BotFather (/newbot), напишите ему /start. Получите chat_id через метод getUpdates Telegram Bot API (не публикуйте токен и не передавайте его в чат). Установите переменные окружения TELEGRAM_BOT_TOKEN и TELEGRAM_CHAT_ID. Для HH установите HH_USER_AGENT с контактным адресом и HH_TOKEN, если требуется авторизация; зарегистрируйте приложение на dev.hh.ru при необходимости. Не храните токены в репозитории.

## Запуск
python radar.py --dry-run
python radar.py

Первый запуск с отправкой уведомит о найденных подходящих активных вакансиях. SQLite хранит ID успешно отправленных вакансий. Для постоянной работы используйте один экземпляр на облачном сервере с постоянным диском и планировщик cron (например, */30 * * * *), настроив переменные окружения безопасно. Не запускайте параллельные экземпляры. При ошибке запуска планировщик должен фиксировать ненулевой код выхода.

## Ограничения
Это локально проверенный прототип, не production. Реальные HH и Telegram запросы не проверены. Поиск HH ограничен 20 страницами на запрос и точными алиасами работодателей, возможны пропуски. Нужны подтвержденные employer_id, прямые разрешенные источники, обработка лимитов и временных ошибок, история всех вакансий, межплощадочная дедупликация, контроль изменений, алерты, LLM-классификация и контрольная выборка. SQLite хранит только отправленные ID. Повтор после неопределенного результата Telegram может создать дубль. Нет гарантии охвата всех работодателей. Перед постоянным запуском проверьте условия доступа HH. Не обходите ограничения источников.
